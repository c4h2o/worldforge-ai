# WorldForge AI — 许可证说明

## 1. Tripo 3D 用什么许可证？（分三类，别混为一谈）

Tripo 有**三个不同主体**，许可证完全不同：

| 主体 | 许可证 | 可商用 | 义务/限制 |
|---|---|---|---|
| **开源模型/工具**（TripoSR、TripoSG、TripoSF） | **MIT**（代码 + 权重均 MIT） | ✅ 完全可商用、可改、可再分发 | 仅需保留版权与许可声明 |
| **JS/TS SDK**（`@tripo3d/sdk`，仓库 tripo-js-sdk） | **MIT** | ✅ 完全可商用 | 同上 |
| **商用 API / 平台**（openapi.tripo3d.ai） | **不是许可证，是《服务条款 ToS》** | ⚠️ 付费用户拥有生成模型、可商用 | 见下方 ToS 要点 |

**已逐条核实（2026）**：
- TripoSR：MIT — *"open source under the MIT license … free for commercial use"*
- TripoSG：MIT（仓库 LICENSE 为 MIT License, Copyright (c) 2025 VAST-AI-Research）
- TripoSF：MIT（`inference.py` 头部 MIT License）
- tripo-js-sdk：MIT — *"License MIT — see LICENSE"*

**商用 API 的 ToS 要点**（源自 Tripo 官方帮助，摘要）：
1. **付费用户拥有生成产物**：生成的 3D 模型版权完全归用户，可商用（使用/复制/修改/二次创作/分发/授权/商业化等）。
2. **竞品限制**：不得用输出创建**与 VAST 产品/服务直接竞争**的模型或服务（这是最关键的一条）。
3. **输入合规**：用户须自行确认用于生成的原始素材（上传的图/文本概念）无版权争议。
4. **公开授权**：把模型设为"公开"即视为授予 Tripo 在服务所需范围内使用/展示该模型。
5. **免责**：Tripo 对任何输出模型的版权状况不承担责任。

## 2. 我们（WorldForge AI）用什么许可证？—— 三条底线

> **① 我们不侵权　② 我们不允许他人侵权　③ 商用需付费**

### 2.1 我们自己的代码：双轨制（非商业免费 + 商业需付费许可）

`LICENSE` = **WorldForge AI Non-Commercial License v1.0**：

| 使用场景 | 是否免费 | 说明 |
|---|---|---|
| 个人 / 教育 / 研究 / 内部测试 / 评估 | ✅ 免费 | 非商业用途，保留版权与许可声明即可 |
| **商业用途**（出售、用于商业产品/服务、用产出物变现、广告推广等） | 💰 **需付费购买商业许可** | 须向 WorldForge AI 购买商业许可（GitHub Issues 联系项目方），价格另公布 |
| 衍生作品 | 随原许可（不得改为宽松许可） | 除非取得商业许可 |

**为什么不用 MIT**：MIT 允许免费商用，与"商用需付费"冲突；故采用**非商业+商业付费**双轨制（source-available 模式），既保留公开透明、便于协作，又保护商业价值。

### 2.2 关键合规条款（对应"不允许他人侵权"）
- **保留权利**：未明确授予的权利一律保留；超出非商业许可的使用=侵权，我方保留追责权。
- **禁止**：移除/篡改署名与许可声明；虚报来源；使用本软件（或允许他人使用）侵犯第三方知识产权；违反第三方组件许可条款。
- **产出物**：软件生成的资产/场景/渲染，非商业免费；**任何商业使用均需商业许可**；用户须保证其输入的素材（上传图/文字/愿景）权利归属清晰、无版权争议。

### 2.3 第三方组件（不被本许可覆盖，各按原许可）
- **TripoSR / TripoSG / TripoSF / @tripo3d/sdk**：均 **MIT**，保留其版权与许可声明即可（见 `THIRD_PARTY_LICENSES.md`）。
- 我们的非商业/商业双轨**不**覆盖这些 MIT 组件——第三方 MIT 部分仍可自由商用（但**不是**"我们允许"，而是 MIT 自身允许）。

### 2.4 对应"我们不侵权"的合规动作
1. **核心图生 3D 优先自托管 MIT 开源**（TripoSR/SG/SF），规避 Tripo 商用 API 的"禁与 VAST 直接竞争"条款。
2. 若用 Tripo 商用 API：仅作**可选质量加成**，遵守其 ToS（付费、不竞争、输入合规）。
3. 输入素材由用户保证权利清晰；本软件生成流程不引入受版权保护的素材。
4. 保留第三方许可声明（THIRD_PARTY_LICENSES.md / NOTICE）。
5. 正式商用部署前请咨询专业律师（非法律意见）。

## 3. ⚠️ 关键策略建议（关系到项目成败）

因为 WorldForge 的**核心链路包含"图生 3D"这一步**，必须想清楚它建立在谁的许可上：

- **不要**把核心图生 3D 能力**完全租用自 Tripo 商用 API**——那等于把核心能力寄生于潜在竞品，且受其 ToS"不得用输出创建与 VAST 直接竞争的服务"限制（我们生成 3D 资产 + 提供生成服务，边界敏感）。
- **推荐**：以**自托管 MIT 开源（TripoSR/SG/SF）为主**（完全自由、可商用、可自建竞品无关的生成能力），**Tripo 商用 API 仅作可选的质量加成/保底**。这与规划文档的 `SelfHostProvider` 为主、`TripoProvider` 为辅一致。

> 一句话：**Tripo 开源=MIT 可随便用；Tripo API=按服务条款付费商用但别和 VAST 竞争；我们自己的代码=MIT。核心图生 3D 优先自托管开源，规避竞品条款风险。**
