# WorldForge AI — SI 单位系统（系统基础）

> 植入来源：用户提供的《7个基本单位对应的常用导出单位及其关系和定义》。
> 用途：作为世界生成的**物理量纲基础**。语义规范 SemanticSpec 中所有实体物理属性（尺寸、质量、力、功率、照度、温度等）一律以 **SI 单位**表达，AI 可经 `system.units` 工具查询任意单位的量纲与定义。

## 1. 7 个基本单位（量纲基）

| 符号 | 名称 | 量纲 [m,kg,s,A,K,mol,cd] | 定义 |
|---|---|---|---|
| m | 米 | [1,0,0,0,0,0,0] | 光在真空中 1/299792458 s 时间间隔内行进的路程长度 |
| kg | 千克 | [0,1,0,0,0,0,0] | 基于普朗克常数 h = 6.62607015e-34 J·s 定义（2019 年起，取代国际千克原器） |
| s | 秒 | [0,0,1,0,0,0,0] | 铯-133 原子基态超精细能级跃迁辐射 9192631770 个周期的持续时间 |
| A | 安培 | [0,0,0,1,0,0,0] | 通过基本电荷 e = 1.602176634e-19 C 定义（电磁学核心基准） |
| K | 开尔文 | [0,0,0,0,1,0,0] | 以玻尔兹曼常数 k = 1.380649e-23 J/K 为基准；水三相点 = 273.16 K |
| mol | 摩尔 | [0,0,0,0,0,1,0] | 1 mol 含阿伏伽德罗常数 N_A = 6.02214076e23 个指定基本单元 |
| cd | 坎德拉 | [0,0,0,0,0,0,1] | 频率 540e12 Hz 单色光在指定方向上的辐射强度 1/683 W/sr |

## 2. 22 个具名导出单位（按领域）

| 领域 | 单位 |
|---|---|
| 空间与周期 | 弧度 rad、球面度 sr、赫兹 Hz |
| 力学 | 牛顿 N、帕斯卡 Pa、焦耳 J、瓦特 W |
| 电磁学 | 库仑 C、伏特 V、法拉 F、欧姆 Ω、西门子 S、韦伯 Wb、特斯拉 T、亨利 H |
| 热学 | 摄氏度 ℃ |
| 光学 | 流明 lm、勒克斯 lx |
| 辐射与化学 | 贝可勒尔 Bq、戈瑞 Gy、希沃特 Sv、卡塔尔 kat |

## 3. 常用组合导出单位（按基本单位关系）

| 基本单位 | 基于它导出的常用单位 |
|---|---|
| 米 m | 平方米 m²、立方米 m³、米每秒 m/s、米每二次方秒 m/s²、每米 m⁻¹ |
| 千克 kg | 千克每立方米 kg/m³、牛顿 N（kg·m/s²）、焦耳 J（kg·m²/s²）、帕斯卡 Pa（kg/(m·s²)） |
| 秒 s | 赫兹 Hz（s⁻¹）、贝可勒尔 Bq（s⁻¹）、库仑 C（A·s） |
| 安培 A | 库仑 C（A·s）、伏特 V（W/A）、欧姆 Ω（V/A）、法拉 F（C/V）、特斯拉 T（kg/(A·s²)）、韦伯 Wb（V·s）、亨利 H（Wb/A） |
| 开尔文 K | 摄氏度 ℃（K 偏移 273.15）、焦每开 J/K（熵、热容） |
| 摩尔 mol | 摩尔每立方米 mol/m³（浓度）、卡塔尔 kat（mol/s）、焦每摩 J/mol（摩尔能） |
| 坎德拉 cd | 流明 lm（cd·sr）、勒克斯 lx（lm/m²）、坎每平方米 cd/m²（亮度） |

## 4. 量纲与组合

- **核心结论**：7 个基本单位本身不"对应"固定几个导出单位，而是**所有导出单位都由这 7 个按量纲组合而成**；其中 22 个被冠以专门名称，其余为组合形式。
- 量纲向量按 [m, kg, s, A, K, mol, cd] 幂次表示，例如：
  - 力 N = kg·m/s² → [1, 1, -2, 0, 0, 0, 0]
  - 能量 J = N·m → [2, 1, -2, 0, 0, 0, 0]
  - 功率 W = J/s → [2, 1, -3, 0, 0, 0, 0]
  - 电压 V = W/A → [2, 1, -3, -1, 0, 0, 0]
  - 照度 lx = lm/m² → [-2, 0, 0, 0, 0, 0, 1]
- 组合形式导出单位数量无上限，可按物理公式无限构造（如 m/s、kg/m³、A/m²）。

## 5. 系统域接入

- **接口**：`GET /api/system/units` → 返回完整注册表 `{system, note, base[7], named[22], combined[], count}`。
- **AI 工具**：`system.units`（可在 TOOL_DEFS 中查询；参数 `q` 可按符号/名称/量纲过滤）。
- **语义规范**：SemanticSpec 中实体物理属性（`physics.dimensions/mass/force/power/illuminance/temperature` 等）一律用 SI 单位；`system.units` 供 AI 换算量纲与确认定义。
- **代码**：`apps/api/src/units.mjs`（零外部依赖，纯数据注册表）。
